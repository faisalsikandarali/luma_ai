## 🚀 Key Architectural Features

1. **Clean Pagination & Category Slicing**:
   - Zero UI clutter: Displays 12 widgets per page by default with smooth pagination numbers.
   - Category filter pills instantly isolate the selected category (showing 50 items across neat pages).
   - Per-page selector: 12, 24, 50 (view full category at once), 100, or All 450.
2. **Default Light Mode with 1-Click Dark Mode Toggle**:
   - Opens in modern clean Light Mode by default.
   - 1-Click Sun ☀️ / Moon 🌙 toggle in Navbar flips into deep Obsidian Cyber Dark Mode.
   - User preference saved in browser `localStorage`.
3. **Tactile Sound FX Engine (Web Audio API)**:
   - Mechanical clicks, pops, laser blips, and success chimes.
   - Built-in SFX Toggle (ON / OFF) directly in the navigation bar.
4. **Multi-Tab Code & Interactive Playground**:
   - **Preview Tab**: Live interactive widget with Responsive Frame size toggles (Desktop 100%, Tablet 420px, Mobile 300px).
   - **Code Tab**: Clean production-ready TSX / JSX snippet with One-Click Copy button.
   - **Install Tab**: One-click copy for `npm install <dependencies>`.
   - **Fullscreen Inspector Modal**: Expand any widget into an isolated canvas with dark, grid, and dot background switchers.
5. **Global `⌘K` / `Ctrl+K` Command Palette**:
   - Instant keyboard navigation to jump to any of the 450 widgets in milliseconds.
